# Dhruv Kadara website (Astro)

    npm install
    npm run dev       # http://localhost:4321
    npm run build     # static site in dist/

- Hero photo: save a wide image as `public/dhruv.jpg`.
- Content lives in `src/pages/index.astro`. Replace `you@example.com`, the `—` impact figures and the `#` social links.
- Styles are in `src/styles/global.css`; change colours in the `:root` tokens.
- Set your domain in `astro.config.mjs` before deploying (Netlify, Vercel, Cloudflare Pages, GitHub Pages).
